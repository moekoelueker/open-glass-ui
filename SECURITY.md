# Security

The project is not yet published and has no supported public release.

Do not open a public issue for a suspected vulnerability. Contact the repository
owner privately before disclosure. A public security contact will be added
before the first release.

Security-sensitive areas include:

- Cross-origin image and video sampling.
- Canvas tainting and object URL lifecycle.
- Shader and filter input bounds.
- Untrusted registry/component source.
- Dependency and release provenance.
