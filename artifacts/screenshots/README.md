# Screenshot evidence

`open-glass-ui-final/` is the current release-candidate visual record. Its
top-level desktop and mobile captures are the Chromium art-direction baseline;
`cross-browser/firefox/` and `cross-browser/webkit/` repeat the same matrix for
engine-specific review.

The numbered and atlas pass directories are preserved research evidence from
before the OpenGlass UI identity was selected. Some images contain the former
internal codename. They are not current brand or marketing assets.
