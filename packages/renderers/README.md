# @open-glass-ui/renderers

CSS, SVG/SDF, and opt-in WebGL rendering engines for OpenGlass UI.

Most applications should install the `open-glass-ui` facade. The default
`renderer="auto"` policy remains CSS-first; controlled-media WebGL is
available through the explicit `open-glass-ui/webgl` entry.
