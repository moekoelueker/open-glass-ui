# @open-glass-ui/recipes

Accessible React component recipes for OpenGlass UI, including navigation,
menus, overlays, forms, feedback, data display, and media controls.

Most applications should install `open-glass-ui` and import
`open-glass-ui/styles.css` once. This scoped package is public dependency-chain
infrastructure; its internals are not the supported consumer entry point.
