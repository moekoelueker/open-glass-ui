## Failed or reverted approaches (do not retry without a new reason)

- Painting the Glass material from a stylesheet rule instead of inline style (D-024). It woke up
  CSS that inline styles had silently overridden; the computed-style diff caught it on the
  showcase.
- A translucent bottom stop on the liquid accent fill: mid-tone accents could not reach 4.5:1
  with any ink. The fill is opaque now.
- `radial-gradient(ellipse 60% min(28%, 0.4rem) ...)`: engines reject `min()` mixing % and a
  length in a gradient size and drop the whole `background`. String-based unit tests passed; the
  browser showed a blank primary button. Guarded by an e2e test in all three engines now.
- Fixed z-indexes for overlays and disclosures, and z-index on unpositioned portal hosts (no
  effect on paint order). Replaced by the layer stack (D-025).
- A context provider rendered only when a tone differs: toggling the app appearance remounted the
  subtree. The provider is always present and wraps the host element (so `dangerouslySetInnerHTML`
  still works).

## A class of bug to keep in mind

React bubbles events from portals through the component tree, not the DOM. Any recipe handler that
wraps arbitrary children (Toast, MenuItems, Card) must check that the event target is inside its
own DOM, or a dialog or menu opened from it loses keys and clicks to it. Most late inspection
findings were this class or layer-ownership edge cases around toasts, popovers and dialogs.

## Verification method worth reusing

A computed-style snapshot of every `[data-ogui-glass]` and `.ogui-*` element on `/`,
`/components` (dark neutral, light coral), `/compare` and `/library/hybrid`, in default,
forced-colors and reduced-transparency modes, diffed against the base commit. It is deterministic
(two baseline runs, zero differences) and it is what exposed the stylesheet-material regression,
the dialog rim ellipse and the dropped gradient. Pair it with real-browser checks of paint order
(`document.elementFromPoint`) for anything layered; jsdom cannot see stacking.
