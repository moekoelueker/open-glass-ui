# Handoff 2026-11-07: per-component tree shaking and 0.5.1

Branch `perf/2026-11-07-per-component-size` from `53a2e99`, pull request 4. Commits use the
`16-0N` phase.

## What happened

1. A consumer-side measurement for the marketing page showed a Button-only import at 28.7 KB
   minified (React external), 40% of the barrel, up from 17.8 KB in 0.4.0.
2. Cause: `dist/index.js` is one module, so a bundler drops an unused component only when its
   declaration is provably free of side effects. Top-level `forwardRef(...)` calls without
   `/* @__PURE__ */` are not. Glass, GlassGroup and GlassSource were unannotated since 0.4.0;
   0.5.0 added `forwardRef` to eleven recipes. Through Glass they kept the theme context, tone
   scoping, the contrast helpers and the CSS material tokens.
3. Fix (16-01, D-026): all fifteen top-level `forwardRef` calls annotated; the liquid muted ink
   built on call instead of in a module-level template literal (tokens identical across 1,080
   option combinations). Button alone is 1,974 B, 2.7% of the barrel.
4. Guards: `tests/unit/tree-shaking.test.ts` (Button and Badge from source, fails on size and
   names leaked recipe classes) and the `verify-packages` bound (under 3,000 B and 5%).
5. Released as 0.5.1 (16-02): branch merged into `main` with a merge commit, annotated `v0.5.1`
   tag, published by `release.yml`.
6. moelueker.com/liquid-glass moved from 0.4.0 to 0.5.1 (website pull request 130): banner,
   380 unit checks, and the 3% per-component figure (2.0 KB of 72.0 KB).
