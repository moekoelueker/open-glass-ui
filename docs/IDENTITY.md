## Public naming gate

Before a public name is selected:

1. Recheck GitHub, npm, major search engines, domains, and relevant trademark
   databases.
2. Check confusingly similar names, not only exact matches.
3. Avoid names that imply Apple ownership, sponsorship, or affiliation.
4. Confirm the final name with the owner before creating a remote or publishing.
